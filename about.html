About Grantlore

Grantlore is a free directory of U.S. private foundations, built for freelance grant writers and small nonprofits who need to know which funders give grants the size they need, where, and whether they accept applications.

Every profile is generated from the foundation's own IRS Form 990-PF e-filing: total assets, grants paid, the full itemized grant list, geographic focus and the application instructions from Part XV. We link each profile to the source filing on ProPublica Nonprofit Explorer so you can check it yourself.

This build (2026-10-30): 6,521 foundations across 52 states and territories, 383,981 itemized grants, selected from 134,223 990-PF filers. 2,164 filed application instructions.

Browsing is free. A paid Premium tier (saved lists, alerts, CSV export) is planned; see pricing.

Grantlore is independent and not affiliated with the IRS, ProPublica or any foundation listed. How we select and process data: Methodology.
